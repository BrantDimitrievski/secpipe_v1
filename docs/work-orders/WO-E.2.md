Implementation notes:
- **Arms (cumulative):**
  - A0 tools only (`--no-ai`, disable `refute`);
  - A1 + refuter (`--no-ai`);
  - A2 + disprover (provider configured, disable `test_evidence`, `verify_records`, `remediate`);
  - A3 + test evidence (needs Docker; sample-limited by `--max-sandbox-runs`);
  - A4 + record verifier.
- **Sampling:** the full Benchmark for A0/A1. A stratified sample for A2–A4 (default 400 cases: 80 per
  CWE, 50/50 vulnerable/safe, fixed seed). The sample list is committed (`docs/eval/sample-400.txt`) by this
  WO, generated by the harness.
- **Cost guard:** refuse to run an AI arm without `--max-agent-calls` and an explicit `--confirm-cost`.
- **Flags:** `--arms LIST`, `--provider P`, `--max-agent-calls N`, `--confirm-cost`, `--sample FILE`,
  `--out DIR` (each arm writes `<out>/<arm>/scorecard.json`), `--dry-run`.
- Note: A2+ on the 400-case sample uses `--deny-path` for `expectedresults` like E.1.

Tests to write: arm → flags mapping; sample generation is stratified and seed-stable; aggregation of
scorecards.
